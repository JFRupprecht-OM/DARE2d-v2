# DARE2D — PyTorch backend (one of two equal backends; see requirements-tf.txt).
#
# Installs the shared stack (requirements-common.txt) plus Torch/torchvision. Powers the
# napari widget's `pytorch` inference backend and the native-Windows GPU training driver
# (training/torch/train.py); detections match the keras backend (parity ~1e-7). Torch 2.6 is
# numpy-1.23 compatible, so the shared numpy==1.23.5 pin is left untouched.
#
#   pip install -r requirements-torch.txt
#
# Different CUDA toolkit? Swap cu124 for your build (e.g. cu121) in the index URL below;
# pip selects the matching Torch wheel. (The .pt weights ship in the Zenodo models.zip next to
# each best.h5: `python -m napari_dare2d.download`; see README "Models & data".)

-r requirements-common.txt

--extra-index-url https://download.pytorch.org/whl/cu124
torch==2.6.0+cu124
torchvision==0.21.0+cu124
